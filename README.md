# Movies Catalog

This is a non-commercial pet project created for educational purposes. The main goals are to improve my application development skills and demonstrate my frontend development abilities. The UI design is based on free web application design templates and was used as a reference only.

Catalog uses TMDB API for fetching movies data so you need to get API key [here](https://developer.themoviedb.org/docs/getting-started) and then go to `Installation` section to successfully run the project

## Installation

1. Install all dependencies executing in the shell `npm install`
2. Set up the environment variables
   1. Execute in the shell `cp .env.example .env`
   2. Define all of required variables in the freshly created `.env` file
